# Der Kriegstisch

Ein interaktiver Taktik-Lehrgang für Autorinnen und Autoren: Formationen, Angriffe, Verteidigung, Gelände und legendäre Manöver vor dem Schießpulver als isometrische Animationen, dazu ein Archiv der Eigenheiten großer Köpfe.

Dieses Repository enthält die fertige Web-App. Über GitHub Pages läuft sie unter `https://timmisg.github.io/kriegstisch/`. Auf iPhone oder iPad öffnest du die Adresse in Safari, tippst auf „Teilen“ und dann auf „Zum Home-Bildschirm“. Danach startet der Kriegstisch im Vollbild und funktioniert auch offline.

Die Schriften Barlow Condensed, Barlow Semi Condensed und Literata stehen unter der SIL Open Font License, die Lizenztexte liegen im Ordner `fonts`.
